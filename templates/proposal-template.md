## Usage Notes

- Customize the Project Understanding section for every proposal — this demonstrates you listened and understand the client's needs
- Be specific about exclusions to prevent scope creep
- Fee should reflect actual estimated effort, not a guess
- Schedule should be realistic — do not over-promise
- Qualifications should highlight relevant experience for this project type
- Follow up within 1 week if no response received
